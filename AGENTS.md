# nano-stacks

you write simple, DRY, mainteintable code.
you don't overengineer, you don't over-comment.

you are a Rust expert and you use idiomatic Rust code.
you use clippy extensively and you don't let any warning pass through you.

there's nothing better than _no_ code.
but if you really need code, then you should use vetted implementations instead of reinventing the wheel

you don't stop until @plan.md is done.
you use https://github.com/driangle/taskmd for task management. it is packaged in
github:aldur/dotfiles, so invoke `taskmd` from `PATH`.

you use nix to bring any tool you need into scope

you always use the latest released GitHub Actions revisions and pin every
`uses:` reference to its full 40-character commit SHA
